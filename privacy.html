Who we are

Salam Kids TV Studio ("the app") is an internal tool used only by the owner of the Salam Kids TV YouTube channel to manage that channel. It is not offered to the public.

What data the app uses

The app uses the YouTube Data API and the YouTube Analytics API, with the channel owner's permission given through Google sign-in (OAuth). It accesses only the channel owner's own account to:

  • upload videos to the Salam Kids TV channel and set their title, description, tags, schedule and privacy status;
  • list the channel's own videos;
  • read view counts and average watch percentage for the channel's own videos.

The app does not access any other user's data, does not collect data from viewers, and does not collect any information from children.

How data is stored

The OAuth access token and a small list of uploaded video IDs are stored only on the channel owner's own computer. No data is sent to third parties, sold, or used for advertising. If the owner enables alerts, short messages about the channel's own videos are sent to the owner's own Telegram chat.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Stored tokens can be deleted from the owner's computer at any time.
